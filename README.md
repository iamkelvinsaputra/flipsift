# FlipSift website

The landing page, privacy policy and terms for [FlipSift](https://iamkelvinsaputra.github.io/flipsift/), a Chrome extension that filters Facebook Marketplace and calculates flip profit for resellers.

Plain HTML and CSS, served by GitHub Pages. Outside links (Chrome Web Store, checkout, Etsy, support) are set in `links.js`.

Questions or problems with FlipSift: [open an issue](https://github.com/iamkelvinsaputra/flipsift/issues).
